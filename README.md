# 준영보카

말해보카의 학습 방식과 화면 흐름(문장 빈칸 채우기, 단어별 오답 설명, 망각곡선 복습)을 혼자 쓰기 위해 다시 만든 영어 단어 학습 웹앱입니다.
안드로이드 Chrome에서 홈 화면에 설치해 앱처럼 쓰는 PWA이며, 학습 기록은 폰 안(IndexedDB)에만 저장됩니다.

## 사용 (안드로이드)

1. Chrome으로 https://jiniusrhee.github.io/junyoung-voca/ 를 연다.
2. 메뉴(⋮) → **홈 화면에 추가** (또는 "앱 설치").
3. 홈 화면 아이콘으로 실행 → 레벨 테스트 20문제 → 매일 "오늘의 어휘".
4. 설정 → **학습 기록 백업 내보내기**로 가끔 기록을 파일로 저장해 둔다. 브라우저 데이터를 지우면 기록이 사라진다.

## 기능

- 어휘 퀴즈: 한글 문장(정답 뜻은 초록색) + 영어 문장 빈칸, 앱 자체 영문 자판, 정답을 다 치면 바로 채점, 힌트 2단계(앞부분 → 정답 보기)
- 오답 설명: 유의어(초록, 감점 없음) / 비슷하지만 안 맞는 말(노랑) / 오답(빨강) 말풍선, 오답 노트에 저장
- 정답 후: 다른 예문, 오답 노트, 말해보기(음성 인식으로 문장 따라 말하기), 단어 정보(뉘앙스·어원), 실전 속도/듣기평가 속도, 다시 듣기
- 음성 모드: 빈칸 단어를 말로 답하기 (안드로이드 Chrome 음성 인식)
- 망각곡선 복습: FSRS 알고리즘(ts-fsrs). "N일 뒤 복습" 배지, 처음 본 단어를 한 번에 맞히면 6개월 뒤 확인
- 레벨 1~30, 적응형 레벨 테스트, 새 단어 정답률에 따른 자동 레벨 조정
- 하루 목표(20/30/50/100/자유)와 트로피, 연속 학습일과 출석 달력, 학습 정보 그래프, 어휘력 추정
- 좋아하는 문장, 내 오답노트, 내가 학습한 어휘, 단어 사전, 백업/복원
- 문법 학습: 단어 카드를 순서대로 눌러 문장 만들기, 틀린 단어 표시, 문법 사전
- 표현 학습: 코스(일상/여행 × 필수/레벨 업) 지도, 패턴 빈칸 문제(길이 보기 → 힌트 → 정답), 오답 노트, 표현 사전, 일별 학습 문장
- 실전 회화: 스토리별 에피소드 대화, 내 차례를 말하거나 입력, AI 없이 핵심 표현·유사도로 채점(별 3개 / S~C 등급), 힌트·모범 답안, 표현 카드, CEFR 학습 난이도
- 리스닝 학습: 객관식(들리는 순서대로 단어) / 주관식(말하기·입력), 발음 구분 연습
- 발음 재생은 폰 내장 음성(무료). 유료 API 없음

## 개발

```bash
npm install
npm run dev              # http://localhost:5173/junyoung-voca/
npm test                 # 단위 테스트 + 화면 흐름 테스트
npm run build            # 타입 검사 + 콘텐츠 검증 + 빌드
npm run content:validate # 단어 팩 검증만
npm run content:coverage # 빈도 목록 대비 수록 현황
```

`main` 브랜치에 push하면 GitHub Actions가 GitHub Pages로 자동 배포합니다.

## 단어 데이터 추가

`public/data/words/level-XX.json`에 항목을 추가하고 `npm run content:validate`로 검증한 뒤 커밋합니다.
작성 규칙은 [CONTENT.md](CONTENT.md)를 참고하세요. 앱은 실행 시 `data/manifest.json`을 확인해 바뀐 팩만 다시 받습니다.
