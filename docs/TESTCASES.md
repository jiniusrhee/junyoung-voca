# 말해보카 대조 테스트 케이스

실제 앱(갤럭시 Z 플립, 같은 계정)에서 직접 조작해 관찰한 반응과, 준영보카가 같은지 기록한다.
확인 방법: 플립에서 두 앱을 번갈아 같은 조작을 하고 화면을 캡처해 비교(scratchpad tools/vexp.py 등).
상태: ✅ 같음 / 🔧 고침(배포됨) / ❌ 아직 다름 / ❓ 미확인

## 어휘 퀴즈 — 키보드 모드

| # | 조작 | 말해보카 반응 | 상태 |
|---|---|---|---|
| V1 | 글자 입력 | 칸 안에 하늘색 글자 + 커서, 아래 보라 말풍선에 같은 글자 | ✅ |
| V2 | 정답보다 길게 입력 | 칸이 글자 너비에 맞춰 늘어남(기본 너비 = 정답 글자 너비), 줄에 안 맞으면 칸째 다음 줄 | 🔧 |
| V3 | 미등록 오답 + 스페이스/확인 | 카드 0.3초 붉게 + 왼쪽 위 '!' , 글자 유지, 말풍선 없음 | 🔧 |
| V4 | 오타(1~2글자 차이) + 스페이스 | '!' + 연보라 말풍선 'relocat_d - 정답과 1글자 달라요.'(틀린 자리 빨간 밑줄) | 🔧 |
| V5 | 등록된 오답(비슷/오답) | 분홍 카드 + 노랑/빨강 설명 말풍선, 오답 노트에 남음 | ✅ |
| V6 | 정답 끝 글자 입력 | 자동 채점: 초록 체크 도장, 칸 글자 초록, 자판은 약 1초 더 보였다가 정답 후 패널로 | 🔧 |
| V7 | 힌트 보기 (입력 중) | 입력이 지워지고 앞 ⅓ 글자가 채워짐, 버튼은 '정답 보기' | ✅ |
| V8 | 힌트 글자 지우기 | 지워지지 않음(고정) | 🔧 |
| V9 | 정답 보기 | 입력 비우고 칸에 정답이 주황색으로 비침, 그대로 쳐야 함, 다음 글자가 대문자면 자판도 대문자 | 🔧 |
| V10 | 여러 단어 정답 | 단어마다 칸, 한 단어가 맞는 순간 초록으로 잠기고 다음 칸으로 자동 이동, 잠긴 단어는 지우기로 안 지워짐 | 🔧 |
| V11 | 문장 첫머리 빈칸 | 자판이 대문자, 첫 글자만 대문자 입력 후 소문자 자판 | 🔧 |
| V12 | 자판 왼쪽 아래 빈 키 | 대문자 전환(한 번: 다음 한 글자만, 두 번 누르면 해제, 잠금 없음, 키 모양 변화 없음) | 🔧 |
| V13 | 지우기 꾹 | 연속 삭제 | 🔧 |
| V14 | 입력 말풍선에 사전 단어 | 밑줄, 누르면 뜻, 처음엔 '눌러서 뜻을 확인해 보세요 ×' | 🔧 |
| V15 | 정답 후 왼쪽 스와이프 | 다음 문제 | 🔧 |
| V16 | 오른쪽 스와이프(문제 중/정답 후) | 이전에 푼 카드(정답 후 패널)로, 왼쪽 스와이프로 복귀 | 🔧 |
| V17 | 문제 중 왼쪽 스와이프 | 아무 일 없음 | 🔧 |
| V18 | 힌트/오답 뒤 정답 | '5분 뒤 복습' 배지, 5~6분 뒤 다시 출제 | 🔧 |
| V19 | 처음 ♥ | 활용 Tip 2장 → 아니요/네 | 🔧 |
| V20 | 정답 후 패널 | 다른 예문/오답 노트(빨간 수)/말해보기/단어 정보/(AI) + 듣기평가 속도/다시 듣기/다음 문제 | ✅ |
| V21 | 나가기(오늘 5문제 미만) | '이대로 가시게요? 5문제를 풀어야…' 나가기/이어서 하기 | 🔧 |
| V22 | 학습 테마 '다이노' | 어휘 퀴즈도 공룡 배경, 올리브 원 + 갈색 줄무늬 막대 + 공룡 | 🔧 |

## 리스닝

| # | 조작 | 말해보카 반응 | 상태 |
|---|---|---|---|
| L1 | 키보드 모드 오답 + 확인 | '!' + 붉은 깜빡임, 입력 유지, 다시 듣기 횟수 유지 | 🔧 |
| L2 | 다시 듣기 | 아이콘 아래 점 3개가 초록→주황→회색 | ✅ |
| L3 | 시작 시트 | 학습 모드 ‹ 주관식 모드 › / 원어민 음성 속도 ‹ 실전 속도 › / 헤드폰 상자 '정확한 듣기를 위해 스피커 볼륨을 확인해 주세요' + 볼륨 확인용 음성 재생 / 오늘의 학습 | ✅ |
| L4 | 객관식 문제 | 카드(알약 진행 + 밑줄 2줄), 보기 2×2(첫 탭 전 U/I/J/K 배지), '다시 듣기' 알약(1 배지, 초록 점 3개); 오답 탭 → 보기가 붉게, 정답 탭 → 단어가 줄에 들어가고(문장 첫 글자 대문자) 진행 알약 초록, 보기 새로 | 🔧 |
| L5 | 주관식(음성) 문제 | 마이크 원 위 'Enter', 아래 '누르고 말해 보세요', 왼쪽 다시 듣기(1), 오른쪽 키보드 모드(0), 첫 진입 시 '음성 인식 권한 안내' 팝업 | 🔧 |
| L6 | 0문제 상태에서 나가기 | 바로 전체 학습으로 (나가기 팝업 없음) | ❓(우리는 5문제 미만 팝업) |

## 문법

| # | 조작 | 말해보카 반응 | 상태 |
|---|---|---|---|
| G1 | 단어 부족 상태로 확인 | 노란 말풍선 '아래 보기에서 N개 단어를 더 사용해서…', 써야 할 카드 ⊕, 자리 틀린 단어 ⇄ | ✅ |
| G2 | 정답 보기 | 정답이 채워지고 정답 후 화면 | ✅ |
| G3 | 홈 '하루 목표 N 개 ✎' / 전체 학습 카드 | 목표 팝업: 캐릭터 + '작은 목표도, 큰 목표도 좋아요. 꾸준히 할 수 있는 목표를 설정해 보세요.' + 3칸(여유롭게/적당하게/열심히) + 열정적으로 + 자유 설정 −N+ (어휘 20/30/50/100, 문법 5/10/20/50) + 취소(1):결정(2) | 🔧 |
| G4 | 내가 학습한 문법 | 메뉴 5개: 일별 학습 문법 / 최근에 틀린 문법 / 일별 학습 문장 / 최근에 틀린 문장 / 역대 가장 많이 틀린 문장 (G 아이콘, 보라 숫자) | 🔧 |
| G5 | 일별 학습 문법 | '모든 문법 보기 ▾'(시트 '확인할 문법 선택': 모든/틀린 문법만) + ‹ 오늘 › , 행 = ❗ + '레벨 17-22' 배지 + 주제 + › ; 최근에 틀린 문법은 날짜별 묶음 | 🔧 |
| G6 | 일별 학습 문장 | '뜻 먼저 보기 ▾'(시트 '가릴 부분 선택': 뜻 먼저/영어 먼저/가리지 않기 + 설명) + '모든 문장 보기 ▾' + ‹ 오늘 › + 학습 기록 토글, 카드(탭해서 영어 보기 / 뜻, ⋮), 아래 '히스토리 학습 (N개) ›' | 🔧 |
| G7 | 최근에 틀린 문장 / 역대 가장 많이 틀린 문장 | 날짜별 묶음 / '틀린 횟수: N회' 라벨, 히스토리 학습 (30개) | 🔧 |
| G8 | 문법 시작 시트 | 원형 링 안에 새로운 문장 / 복습할 문장 / 틀린 문장 수, 왼쪽 아래 캐릭터, 오른쪽 아래 0/10, '오늘의 학습' | 🔧 |
| G9 | 문법·리스닝·표현 상단 바 | 올리브 원(물방울 아이콘) + 민무늬 막대 + 주황 0/10 (줄무늬 막대·공룡 손잡이는 어휘만) | 🔧 |
