# 말해보카 기능 명세 (실제 앱 관찰 기록)

2026-10-23, 사용자 폰(갤럭시 S25 울트라, 다크 모드, 학습 테마 "다이노를 찾아서")에서 무선 adb로 직접 관찰한 내용.
캡처 원본은 로컬 `ref/phone/` (깃 제외). 말해보카의 그림·문구·데이터는 복사하지 않고 구성과 동작만 따른다.

**제외 범위 (사용자 지시):** 리그, 캐릭터 꾸미기/상점, 유료 원어민 음성, 발음 정밀 진단(문장 발음 진단). AI 질문 답변·AI 추가 설명·AI 문장 분석은 유료 API가 필요하므로 제외.

## 공통

- 하단 탭: 홈 / 학습 통계 / 전체 학습 / (리그) / (프리미엄)
- 학습 화면 공통: 상단 뒤로 + 진행 막대(오늘 n/목표) + 톱니바퀴, 테마 배경, 카드 왼쪽 위 레벨 탭, 오른쪽 위 배지(New / N일 전 / 잠시 후 복습 / N일 뒤 복습)
- 정답 후 하단: 도구 아이콘 줄 + 큰 버튼 3개(모드별 왼쪽 버튼이 다름) — 다크 모드에서는 어두운 버튼에 보라색 아이콘
- 학습을 마치고 나가면 리그 팝업(제외)

## 전체 학습 탭

- "학습 모드" 칩: 어휘 / 문법 / 표현 / 실전 회화 / 리스닝
- 칩마다 색 카드(어휘 보라, 문법 하늘, 표현 분홍 beta, 실전 회화 초록 beta, 리스닝 주황) + ▶, 트로피 리본(목표 달성 시)
  - 어휘: 하루 목표 20개 ✎ / 목록: 내가 좋아하는 문장, 내가 좋아하는 오답노트, 내가 학습한 어휘, 내 단어장, (AI 질문 답변 모아보기)
  - 문법: 하루 목표 10개 ✎ / 내가 학습한 문법, 북마크, (AI…)
  - 표현: 학습 코스 | 여행 영어 - 레벨 업 / 내가 학습한 표현
  - 실전 회화: 스토리 | LA 인싸의 스몰토크 챌린지 / 최근 학습한 에피소드, (AI…)
  - 리스닝: 하루 목표 10개 ✎ | 실전 속도 ✎ / 내가 학습한 문장, 북마크
- 사전: 단어 사전, 문법 사전
- 기타: 발음 구분 연습, 사용 설명서

## 시작 팝업 (▶ 누르면)

- 어휘(목표 달성 후): 학습 코스(통합 코스, 변경), 새로운/복습할/재도전 단어 수, 추가 개수 스테퍼, 추가 학습
- 문법: 새로운 문장 n개 / 복습할 문장 n개, 0/10, 오늘의 학습
- 리스닝: 학습 모드 ‹ 주관식 모드 | 객관식 모드 ›, 원어민 음성 속도 ‹ 실전 속도 | 듣기 평가 속도 ›, 헤드폰 그림 + "정확한 듣기를 위해 스피커 볼륨을 확인해 주세요." + 볼륨 확인용 음성 재생, 오늘의 학습

## 문법 학습

- 카드: 위 한국어 문장, 아래 빈 줄(끝 문장부호만 오른쪽에 표시), 레벨 탭 "레벨 16-2"
- 아래 단어 카드: 알파벳순, 오답용 단어 섞임(excited/exciting, is/was, ate/eaten, pizza/pizzas, already/yet). 누르면 답 줄로 올라가고 원래 자리는 빈 칸으로 남음. 답 줄의 단어를 누르면 되돌아감. 첫 단어는 자동 대문자. 축약형은 한 카드(You've)
- 오른쪽 아래 마이크 버튼(음성으로 문장 말하기)
- 하단: 정답 보기(보라, 체크 아이콘) + 확인(단어가 하나라도 있으면 보라)
- 확인 후 틀리면 노란 말풍선 + 단어 표시(실시간 갱신):
  - 쓰면 안 되는 단어: 빨간 글자 + 빨간 ⊖ 배지 → "표시된 단어들을 옮겨서 문장을 다시 만들어 보세요." 써야 할 단어 카드에 초록 ⊕ 배지
  - 단어가 모자람 → "아래 보기에서 N개 단어를 더 사용해서 문장을 완성해 보세요." (써야 할 카드에 ⊕)
  - 순서만 틀림 → 자리가 틀린 단어에 주황 ⇄ 배지 + "단어의 순서를 바꿔보세요."
- 정답 후: 카드 위 보라 띠 "레벨 16-2 | to부정사 - 가목적어 it", 배지 "잠시 후 복습", 마지막 단어에 문장부호 붙음
  - 도구: (AI 질문 답변) / 오답 노트(빨간 숫자 배지) / 말해보기 / 사전 검색 / (문장 발음 진단)
  - 큰 버튼: 문법 사전 / 다시 듣기 / 다음 문제
- 오답 노트: "모범답안"(문장 + 번역), "복수정답"(다른 정답 문장, 다른 부분 빨간색, 뉘앙스 설명)
- 정답 보기: 바로 정답이 채워지고 정답 후 화면

## 문법 사전

- "문법 & 문장 검색": 탭 문법 검색 / 문장 검색, 왼쪽 분류(문장의 기초 …), 오른쪽 주제 목록, 아래 검색창 + 확인
- 주제 글: 번호 + 제목, 예문 말풍선(캐릭터 + 영어 + 번역, 핵심어 강조), 질문으로 시작하는 대화체 설명, 노란 강조/밑줄, 링크 칩(바로 위, 목적격 보어), 문장 구조 그림(덩어리 + 아래 라벨)

## 리스닝 학습

- 레벨 1~50 ("레벨 41")
- 카드 위쪽: 번역 자리(회색 막대, 객관식에서는 초록 진행 막대), 아래쪽: 단어 수만큼 밑줄
- 객관식: 큰 버튼 4개(단어). 다음 단어를 누르면 초록 글자로 채워지고 그 버튼은 다음 단어로 교체, 끝에 가면 빈 반투명 칸. 틀리면 버튼이 어두운 빨강 + "Listen Carefully"로 다시 재생. 틀린 뒤 맞힌 단어는 흰 글자
- 주관식: 기본 음성 모드(큰 마이크, 왼쪽 "다시 듣기" + 남은 횟수 점 3개, 오른쪽 "키보드 모드"), 키보드 모드는 소문자 자판 + 가운데 입력칸
- 다시 듣기는 최대 3번(점: 초록 → 노랑 → 회색)
- 정답 후: 핑크 손글씨 "Great!! 두번 듣고 맞혔어요!"(1번 Perfect, 2번 Great, 3번 Good, 실패 Nice try), 번역 표시, 문장 밑줄
  - 도구: x0.8 듣기 / 듣기평가 속도 / 말해보기 / 북마크 / (문장 발음 진단)
  - 큰 버튼: x0.5 듣기 / 다시 듣기 / 다음 문제

## 단어 사전

- "단어 & 문장 검색": 탭 단어 검색 / 문장 검색 / (AI 문장 분석), 최근 검색(전체 삭제, ×), 아래 검색창 + 확인

- 음성 속도 및 크기: 원어민 발음, 성별, 속도, 음성/효과음/키 입력 소리, 키 입력 진동, 연속 학습 달성 시 진동, 앱 무음 모드로 시작하기
- 그 외: 학습 중 응원창 보기, 키보드 단축키 표시, 다음 문제 버튼 표시, 음성 인식 대기시간

## 표현 학습 (2026-10-23 관찰)

- 메인: 헤더 '표현 학습 beta' + 트로피 수·별 수, 가운데 코스 선택 버튼(여행 영어 - 레벨 업 ⌄), 오른쪽 노트 아이콘(일별 학습 문장), 구불구불한 길 위의 별 동전(진행 단계)과 그림, FINISH 표지판, 아래 '오늘의 학습'
- 코스 선택: '학습할 카테고리를 선택해 주세요 / 코스는 언제든지 바꿀 수 있어요', 현재 학습 중인 코스 카드, 전체 코스(일상 영어 - 필수 ★, 일상 영어 - 레벨 업 ★★, 여행 영어 - 필수 ★, 여행 영어 - 레벨 업 ★★ …) 각각 진행 막대와 %

- 문제(0/15): 카드 위 초록 띠에 말풍선 아이콘 + 패턴('~로 계산할 수 있을까요?'), 배지(N일 전), 카드 위쪽에 캐릭터 + 상대 말풍선(That'll be $30.21. Cash or credit?) + 번역 아이콘, 아래쪽에 패턴 빈칸 + 나머지 문장(Apple Pay?), 한국어 문장(패턴 부분 초록)
- 도구줄: 처음엔 '길이 보기'(빈칸을 단어 수만큼 나눔) → 그다음 '힌트 보기', 오른쪽 '음성 모드'. 자판은 어휘와 같음(아포스트로피 키 포함)
- 입력하면 단어 칸별로 채워지고 맞는 단어는 초록. 틀린 채로 확인하면 그대로 다시 입력
- 정답 후: 배지 'N개월 뒤 복습', 입력 말풍선, 도구 다른 예문 / 오답 노트(미리 정의된 오답 설명, 예: can I pay by — by는 카드일 때 …) / 말해보기 / 사전 검색 / (문장 발음 진단), 큰 버튼 표현 사전 / 다시 듣기 / 다음 문제

## 실전 회화 (2026-10-23 관찰)

- 메인: '실전 회화 학습' + 오른쪽 '⚙ 난이도 · C1', 스토리 카드 캐러셀(큰 그림, 제목 'LA 인싸의 스몰토크 챌린지', 부제 '스몰토크가 만든 특별한 한 달', '이어서 학습' 버튼, 아래 진행 막대), '문장 복습 ★추천' 카드(복습하기 ›, 한국어 문장, 출처 에피소드), '최근 학습한 에피소드', 카테고리별 가로 목록(일상, 연애, 학교, 스페셜, 여행)
- 에피소드 시작: 배경 그림 + 인물, 위에 스토리 제목·진행(6/16)·'전체 에피소드 보기', 가운데 미션 문구('새로 연 저 식당, 맛있을까요? 이웃에게 물어봐요.'), '시작하기' 또는 '처음부터 하기 / 이어서 하기'
- 내 차례: 아래 패널에 내가 할 말(한국어, 단어마다 점선 밑줄 — 누르면 영어 표현, 처음에 툴팁 '단어를 누르면 영어표현을 확인할 수 있어요'), 오른쪽 위 별 3개, 버튼 힌트 보기 / 마이크 / 키보드 모드
- 키보드 모드: 도구줄 힌트 보기 / 음성 모드 + 자판(쉼표·마침표 키 있음, 대문자 자동)
- 힌트: 보라 상자에 표현 힌트('길모퉁이에'는 around the corner로 …), 그다음 버튼은 '모범 답안'
- 채점: 'Perfect!!'(별 3, 초록 설명 상자) / 'Nice Try!'(별 0, 빨간 설명 상자), 내 문장, '모범 답안' 초록 글자, 버튼 줄 모범 답안 듣기 / (AI 질문 답변) / 재도전 / 다음 문제
- 상대 차례: 말풍선(영어 + 듣기 아이콘 + 한국어 번역)
- 표현 카드: 'around the corner / 위치가 아주 가까운' + 설명 + '어휘 학습에 추가하시겠어요?' 괜찮아요 / 좋아요
- 위쪽 진행 막대 끝에 등급 배지(S 금색 날개)
- 전체 에피소드: 세로 타임라인, 완료 ✓ + 등급 배지(A 금 육각, B 은 육각), 현재 에피소드에 '학습 시작', 이후 잠금
- 학습 난이도: CEFR A1~C2 설명 카드, 취소 / 확인

## 학습 통계 숫자 (2026-10-24 관찰)

- 기간별 '오늘의 학습 정보': 총 학습 시간 / 총 학습 문제 타일, 모드별 줄(어휘: 새 문제 n 복습문제 n + 복습 정답률 n% ›, 문법·표현도 같음, 리스닝: 문제 n + 최고 레벨 n ›), '보통 금요일에는? 평균 8분 동안 20문제를 학습해요.', 아래 연간 학습·학습 시간

### 단계
- 처음: 빈칸이 **한 덩어리**(낱말 수를 모르게, 오른쪽 끝이 흐리다). 자판은 대문자, 정답에 아포스트로피가 있으면 ' 키가 보인다. 도구줄 왼쪽은 '길이 보기'(둥근 네모 안의 ↔).
- '길이 보기': 빈칸이 낱말 수만큼의 칸으로 갈라지고(That's 는 [That]'[s] 처럼 아포스트로피가 미리 보인다 — 우리는 한 칸) 단추가 '힌트 보기'로 바뀐다. ' 키는 사라진다.
- '힌트 보기': 첫 낱말의 **앞 2글자**가 초록으로 채워지고(What → Wh, Is → Is — 낱말이 끝나면 커서가 다음 칸으로) 말풍선에도 보인다. 단추는 '정답 보기'. → `exprPrefix`.
- '정답 보기': 채워진 글자는 그대로 두고 나머지 정답이 주황으로 비친다(어휘와 달리 입력이 비워지지 않는다).
- 치는 대로 보라 말풍선에 보이고, 제자리의 낱말과 같게 친 칸은 초록이 된다. 아포스트로피 · 대문자는 치지 않아도 붙는다(thats → That's). → `bare` · `shownWord`. 다 치면 저절로 채점.
- 오답: 등록되지 않은 답은 '확인'을 눌러도 **눈에 보이는 반응이 없다**('Zz' 하나만 쳤을 때도, 칸을 다 채운 'Do you eat this food' 도 그대로). 등록된 답의 반응은 보지 못했다 — 우리는 어휘처럼 카드가 붉어지고 설명 알약이 뜬다.
